# Roadmap

1. **Escrow program (Anchor)** — on-chain receipt NFTs, refund window, dispute hook.
2. **Session tickets** — one payment, N requests; burst pricing for agent loops.
3. **Framework middleware** — Hono / Express / Next.js route-handler adapters.
4. **Wallet-signer abstraction** — browser wallets, Squads multisig payers, custodial signers for agent fleets.
5. **Mainnet descriptor + spec upstreaming** to the x402 registry.
6. **Replay registry** — optional on-chain nonce account for high-value resources.
